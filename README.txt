NR19 MEN — Ready Website
==========================
1. Unzip this folder.
2. Open index.html in Chrome/Edge.
3. The website works without a server.
4. Product filters, search, cart and local cart storage are included.
5. This is a front-end demo. For real payments, orders, inventory and admin login, connect a backend/payment provider.

To customize:
- Edit products in script.js
- Change text in index.html
- Change colors/fonts/layout in style.css
